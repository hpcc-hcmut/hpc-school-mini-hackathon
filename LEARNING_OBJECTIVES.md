# Learning Objectives

By completing this hackathon, students will learn to:

- **Submit and monitor a GPU-based Slurm workflow:** Understand how to submit batch jobs and manage resource allocations for multi-agent LLM systems on a cluster.
- **Use code, configurations, Slurm scripts, and benchmark logs as evidence:** Extract ground-truth facts from realistic HPC repository artifacts.
- **Design a multi-agent workflow:** Implement extraction, reasoning, aggregation, and verification roles effectively.
- **Produce traceable answers:** Generate answers that provide exact file and line evidence citations alongside comprehensive workflow metadata.
- **Reason about quality-runtime-resource trade-offs:** Balance the accuracy of complex LLM calls against cluster resource limits, runtime constraints, and model size.
